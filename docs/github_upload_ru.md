# Загрузка через GitHub Desktop

1. На github.com/new создай публичный пустой репозиторий `marketplace-unit-economics`. Не добавляй README через сайт.
2. В GitHub Desktop: File → Clone repository → URL; вставь адрес репозитория.
3. Repository → Show in Explorer. Скопируй **содержимое** этой распакованной папки, не ZIP, в папку репозитория. Не трогай скрытую `.git`.
4. Проверь, что видны отдельные папки `data`, `src`, `sql`, `notebooks`, `reports`, `figures`, `tests`, `docs` и файл `README.md` в корне.
5. В GitHub Desktop: Changes → Summary `Initial commit: unit economics` → Commit to main → Push origin.
6. Открой репозиторий в браузере, проверь README и два графика.

Никогда не загружай настоящие конфиденциальные данные компаний, ключи и пароли.
